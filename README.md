# Android Agent

Личный агент дневника питания для **Android 11+ / Realme 6 Pro**. Получает команды из приватного Telegram-чата и управляет установленным FatSecret через Accessibility. Для ИИ используется текущая подписка Claude Code на ПК: API-ключ не нужен, ПК должен быть включён. Точные команды `/meal` работают без ИИ и ПК.

Ветка **0.4.0** добавляет управление экраном и ИИ через подписку на ПК. Исправление времени из 0.3.1 сохранено: помощь, статус и остановка не зависят от часов телефона; свежесть действий проверяется по HTTPS-времени Telegram и монотонному таймеру Android.

В рабочей ветке добавляется экранный сценарий: поиск продукта, выбор варианта, установка граммов, предварительный просмотр и явное подтверждение. Фактические результаты runtime-проверки публикуются в [PROGRESS.md](docs/PROGRESS.md); наличие кода не означает приёмку MVP. Прежний developer API сохранён как отдельный эксперимент и скрыт в основных настройках.

## Начало работы

1. На вкладке **Telegram** введи токен бота и свой числовой ID, сохрани и проверь соединение. FatSecret и ИИ для этого не нужны.
2. На **Главной** нажми **Запустить**, дождись состояния **Работает** и открой бота. В чате появятся кнопки и помощь `/help`.
3. На вкладке **FatSecret** открой обычное приложение и войди в свой аккаунт. Включи специальные возможности Android Agent. Держи телефон разблокированным во время управления.
4. Для свободного текста подключи [помощник по подписке на ПК](docs/PC_BRAIN_RU.md). Developer-ключи и платный API не нужны.

## Возможности

- Telegram: проверка токена/webhook, постоянное уведомление, явные запуск/остановка, ошибки авторизации и второго приёмника, переподключение при потере сети. Принимается только настроенный приватный чат с совпадающим отправителем; группы и пересылки отвергаются.
- `/today` читает видимую сводку дневника с экрана без ИИ. Это не полный экспорт продуктов. `/status`, `/help` и `/stop` доступны без входа FatSecret.
- `/meal обед банан=100` готовит один продукт на сегодня без ИИ. Можно использовать английские типы приёма пищи или указать дату явно. Нужны выбор `/pick 1 НОМЕР`, проверка порции и `/confirm КОД`. `/cancel` отменяет черновик.
- Сохранение выполняется один раз после синхронной записи журнала. Новые записи блокируются до ручной проверки результата в FatSecret; автоматического повтора нет. Сначала проверь дневник и затем снимай блокировку в приложении.
- Секреты, offset и журнал операций зашифрованы Android Keystore; backup отключён. Формы защищены от скриншотов. Обезличенная **Диагностика для скриншота** не содержит токенов, ID и еды.
- Accessibility ограничен FatSecret. Действия определяет проверяемый фиксированный сценарий, модель не получает команды управления телефоном. Изменившийся или неоднозначный экран останавливает выполнение.

## Сборка и тесты

JDK 17, Gradle wrapper 8.9, Android SDK 35 / build-tools 35.0.0. Минимальный Android API 30, target 35.

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest
python -m unittest discover -s pc -v
```

На Windows используй [scripts/dev.ps1](scripts/dev.ps1) по [инструкции](docs/DEVELOPMENT_RU.md). Локальные инструменты и ключ подписи лежат вне Git. APK: `app/build/outputs/apk/debug/app-debug.apk`. CI публикует APK, тесты и скриншоты чистого Android 11 эмулятора. [scripts/device-smoke.sh](scripts/device-smoke.sh) проверяет Keystore, перезапуск, службу и русский интерфейс; физические устройства и непустую конфигурацию он отвергает.

## Границы проверки

Сборка, JVM-контракты и эмулятор не доказывают доступ к существующему FatSecret-аккаунту, качество распознавания фото, установку через Play Protect или фоновую работу на Realme. Эти проверки описаны в [инструкции](docs/INSTALL_RU.md). Не отправляй credentials в Issues и не включай платные API без отдельного решения.

Поиск продуктов использует регион установленного FatSecret; иногда нужно английское название. В рабочей ветке добавлены фото и локальное распознавание голоса, с отдельными runtime-проверками в трекере. Уточнения хранятся в памяти ПК до 15 минут. Произвольные даты и несколько продуктов за запрос пока не поддержаны экранным режимом. После перезагрузки или принудительной остановки агент запускается пользователем заново. Временный HTTPS tunnel требует обновления адреса после перезапуска.

Используются OkHttp и Android platform API. Сторонний код агентов не копировался; [аудит](docs/UPSTREAM.md), [архитектура](docs/DECISIONS.md), [лицензии в APK](app/src/main/assets/licenses).
