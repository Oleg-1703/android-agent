# ИИ по текущей подписке

Telegram -> Android Agent -> помощник на твоём ПК -> Claude Code по подписке -> черновик -> поиск в установленном FatSecret -> выбор продукта -> подтверждение.

API-ключи FatSecret и ИИ не требуются. ПК, интернет и помощник должны работать. Лимиты подписки Claude сохраняются. Команда `/meal` работает без ИИ и ПК. Телефон должен быть разблокирован, Accessibility Android Agent включена, вход в обычный FatSecret выполнен.

## Данные и ограничения

На ПК отправляется текст еды и локальная дата. Помощник не получает Telegram-токен, developer-ключи, пароль FatSecret, дерево экрана или дневник. Текст обрабатывается Claude через установленный CLI с подписочным входом. Файлы, shell, MCP, навыки, пользовательские hooks и сохранение сессии отключены. Модель формирует только JSON-черновик. Нажатия выполняет фиксированный Android-сценарий.

Подписочный режим пока принимает текст. Фото и голос ещё не подключены. Экранный исполнитель поддерживает один продукт за запрос и сегодняшнюю дату. Неоднозначные или изменившиеся экраны останавливают работу. После единственного нажатия SAVE запись блокируется до ручной проверки дневника. Автоматического повтора нет.

## Запуск

Нужны Python 3.11+ и актуальный Claude Code с подписочным входом (`claude auth login`). Вход через платный API помощник отклоняет. Дополнительные Python-пакеты не нужны.

Из корня репозитория:

```powershell
python pc/brain.py --config "$env:LOCALAPPDATA/AndroidAgent/brain.json" --init
python pc/brain.py --config "$env:LOCALAPPDATA/AndroidAgent/brain.json"
```

На этом ПК вместо `python` используй `C:/Users/Oleg/.local/bin/python3.14.exe`. Приватный файл содержит случайный `pairing_token`. Его нельзя публиковать или добавлять в Git. Помощник слушает только `127.0.0.1:8766`, не опрашивает Telegram и одновременно выполняет не более одного запроса к подписке.

Для телефона нужен HTTPS-адрес этого локального сервиса. Для проверки используется официальный Cloudflare Quick Tunnel:

```powershell
cloudflared tunnel --url http://127.0.0.1:8766 --no-autoupdate
```

В Android Agent -> ИИ введи HTTPS-адрес и `pairing_token` из приватного файла, включи согласие, сохрани и запусти агента. Это код доступа к твоему помощнику, не платный API-ключ. Запрос без кода не запускает модель.

Quick Tunnel - временный адрес для тестирования. После перезапуска адрес меняется, гарантий доступности нет. Для постоянной работы нужен устойчивый HTTPS-адрес, например собственный именованный tunnel. Cloudflare обрабатывает HTTPS-трафик; схема предназначена для этого личного проекта.

Проверки конкретной версии: [PROGRESS.md](PROGRESS.md). Официальные справки: [CLI](https://code.claude.com/docs/en/cli-reference), [вход по подписке](https://code.claude.com/docs/en/authentication), [ограничения Quick Tunnel](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/).
