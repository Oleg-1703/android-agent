# Проверка на ПК - 15.11.2026

## Результат и границы

Локально собран прототип 0.3.0 с русским интерфейсом. Установлен Android 11 / API 30 AOSP x86_64 эмулятор, JDK 17 и SDK 35. Проверены интерфейс, Keystore, сохранение конфигурации и живой Telegram из Android. Олег подтвердил отсутствие developer-доступа FatSecret. OAuth/чтение/запись реального дневника, фото/голос через модель, Realme/Play Protect и OEM-энергосбережение не проверены. Никакие реальные записи еды не создавались, платные API не подключались.

Исходная реализация взята из PR #6, отчёт о неудачном пользовательском тесте из PR #7 сохранён рядом. Причина молчания на Realme не установлена: нет лога того телефона. Проверка предоставленного бота подтвердила валидный токен и отсутствие webhook. Найденный старый запрос уже превышал прежний пятиминутный лимит. Новая версия объясняет пропуск устаревшего запроса и показывает ошибки подключения; это улучшение диагностики, а не доказательство причины старого сбоя.

## Обезличенный вывод инструментации

```text
PASS: Activity; FLAG_SECURE; Keystore ciphertext/round-trip; safe unconfigured service stop
PASS: encrypted state survives force-stop/process restart
PASS: five Russian tabs; start/invalid-owner guards; encrypted form save and blank-secret retention; safe diagnostics; secure flag restored; empty-config screenshots
PASS: live Telegram authentication on Android; no webhook; configuration encrypted; temporary import removed
PASS: live Android getMe/getWebhookInfo/getUpdates/sendMessage; secure screen; UI stop cancels and releases the same live poller
PASS: starting offline shows reconnecting in production UI
PASS: service recovers after emulator network is restored
PASS: normal application UI stops the recovered service
INSTRUMENTATION_CODE: -1
```

Каждая фаза закончилась кодом -1 (успех). В живой проверке не используются отдельные фазы запуска и остановки: старт новой instrumentation сам завершает целевой процесс. Остановка проверяется в той же фазе, затем credentials удаляются. Test APK нельзя устанавливать на личный телефон; runner дополнительно отвергает физические устройства.

## Воспроизводимость и артефакты

Команды в [DEVELOPMENT_RU.md](../DEVELOPMENT_RU.md). Локальные скриншоты `.local/qa/default` и `.local/qa/narrow`, автономный отчёт `.local/report.html`, APK в `app/build/outputs/apk/debug/`. Секретов в этих скриншотах нет: снимались пустые формы, до ввода синтетического токена. Эти генерируемые файлы не включаются в Git. CI отдельно публикует APK и снимки чистого эмулятора.

Сборка из прямого Windows-пути с кириллицей первоначально дала ClassNotFoundException JVM-тестов. Junction на этот же checkout устранил проблему; переносить исходники не пришлось. Все приведённые успешные проверки выполнены через документированную конфигурацию.
