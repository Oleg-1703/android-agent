# Установка на Realme 6 Pro / Android 11

Это проверяемая сборка для тестирования, пока не подтверждённая как готовый MVP. Для работы после установки компьютер не нужен. Интернет нужен для Telegram, FatSecret и, при включении, облачного LLM. Отдельного сервера проекта нет.

## APK и безопасность
1. Скачайте `android-agent-debug` в Artifacts успешного GitHub Actions и распакуйте ZIP. Для скачивания артефактов GitHub обычно нужен вход в аккаунт.
2. На телефоне разрешите установку из выбранного браузера/файлового менеджера и установите APK. Минимальная версия — Android 11 (API 30).
3. Разные CI-запуски используют временный debug-ключ: обновление поверх прошлой CI-сборки может потребовать удаления приложения. Удаление очищает конфигурацию и журнал неопределённых операций — сначала проверьте дневник. Это не release-сборка с постоянной подписью.
4. Токены вводятся только в приложении. Секреты и состояние зашифрованы AES-GCM ключом Android Keystore; резервное копирование отключено. Не отправляйте токены, пароли или UI-дампы в Issues/Telegram/чат разработки. Снимки экрана настройки заблокированы.

## Telegram
1. Создайте бота через BotFather. Введите его токен в Android Agent.
2. Укажите свой положительный **личный** Telegram chat ID. Агент проверяет одновременно тип `private`, chat ID и sender ID; группы и пересланные сообщения отвергаются.
3. Нажмите Save. Любое сохранение останавливает агента и сбрасывает неподтверждённый обзор; пустое поле секрета сохраняет прежнее значение. Для удаления всех токенов очистите данные приложения после проверки дневника.
4. Запустите личный диалог с ботом, нажмите Start Telegram agent в приложении, затем отправьте `/help`. Не запускайте другой poller для этого же бота. При существующем webhook удалите его средствами управления Bot API; ошибка 409 останавливает агента до исправления.
5. Агент работает с постоянным уведомлением и кнопкой Stop. Автозапуска после перезагрузки/убийства процесса нет — откройте приложение и нажмите Start. На Android 13+ предоставьте разрешение уведомлений для видимой кнопки Stop.

Сообщения старше пяти минут игнорируются. Offset сохраняется **до** исполнения: аварийное завершение может потерять одну команду, но не должно повторить запись. После сбоя проверьте `/status`, а перед повторной отправкой еды — дневник.

## Существующий аккаунт FatSecret
1. Получите Consumer Key/Secret своего приложения на platform.fatsecret.com. Право доступа к профилям, ограничения тарифа/региона и ограничения аккаунта определяются FatSecret.
2. Введите Consumer Key/Secret в Android Agent и сохраните. Нажмите Authorize existing FatSecret account.
3. В открытом браузере войдите в **существующий** аккаунт FatSecret и разрешите доступ. Пароль вводится только на сайте FatSecret.
4. Скопируйте отображаемый verifier в поле приложения и нажмите Complete FatSecret authorization. Используется официальная схема OAuth 1.0 с `oauth_callback=oob`; новый профиль вместо вашего аккаунта не создаётся.
5. Нажмите Check today's existing diary. Сравните число записей с приложением FatSecret. Пустой день не доказывает правильность выбранного аккаунта: проверьте на дате с известными записями при первом тестировании.
6. Нажмите Start Telegram agent после завершения настройки.

Пример тестовой команды (подставьте нужную дату):

```text
/meal 2026-11-12 lunch chicken breast cooked=200;rice cooked=150
```

- Допустимые приёмы пищи: `breakfast`, `lunch`, `dinner`, `other`.
- Порции задаются в граммах; дата обязательна. Если поиск не находит русское название, используйте английское. В текущем API-поиске регион по умолчанию US.
- Бот покажет до пяти кандидатов на каждый продукт. Выберите точный продукт, включая приготовление/бренд: `/pick 1 2`, затем `/pick 2 1`.
- После всех выборов проверьте дату, приём пищи, граммы и порцию. `/confirm CODE` записывает еду; `/cancel` отменяет обзор. Код действует 15 минут и меняется после изменения выбора.
- Если продукт уже есть на этой дате, обзор предупреждает о возможном дубле. Подтверждайте только осознанное повторное добавление.
- Успех сообщается только после чтения созданной записи с совпадающими ID, датой, приёмом пищи и количеством единиц.

**Если ответ потерялся, не отправляйте еду повторно вслепую.** `/status` показывает последний проверенный результат/блокировку. При неопределённой записи агент прекращает добавление остальных продуктов и блокирует новые записи. Остановите агента, дождитесь окончания запроса, откройте дневник и проверьте частичный результат. Только затем нажмите I inspected the diary: acknowledge uncertain write в приложении. Это не удаляет записи и не повторяет запрос; отправьте новой командой только недостающие позиции. Много продуктов записываются последовательно, транзакции на всю тарелку нет.

## Фото, естественный текст и голос (по желанию)
Укажите HTTPS base URL OpenAI-compatible API, ключ, модель для текста/изображений и модель транскрипции. Включите согласие на отправку еды этому провайдеру и сохраните. Используются `/chat/completions` с JSON-ответом и `/audio/transcriptions`. Поддержка этих форматов зависит от провайдера; live-вызовы модели ещё не проверены.

Пример подписи к фотографии: «Добавь в FatSecret сегодня на обед: курица варёная 200 г, рис варёный 150 г». Вес нельзя достоверно определить по фото; указывайте его явно. При пропущенных/неоднозначных данных модель должна запросить уточнение. В любом случае продукты и количества нужно выбрать/подтвердить перед записью. Ответ модели не может сам вызвать `/confirm` или Android-действия.

Ограничения: фото до 4 MB; голос до 120 секунд/8 MB. Файлы находятся в памяти и не сохраняются на диск. Группировка Telegram-альбомов и последовательный диалог для уточнения пока не поддержаны: отправляйте один снимок с полной подписью или новую полную команду.

## Android Accessibility и Realme
Для записи через API Accessibility **не требуется**. Включайте службу в системных настройках только для локальной проверки механизмов автоматизации. Доступ ограничен `com.fatsecret.android`; UI-дерево не отправляется в Telegram/LLM. Есть внутренние примитивы поиска по resource ID, click, setText и scroll с ограничением действий и локальным подтверждением. Универсальные команды управления телефоном и сценарий записи через UI пока не подключены; неизвестные элементы не угадываются.

На Realme вручную разрешите фоновую работу приложения, исключите его из энергосбережения при необходимости и проверьте работу с выключенным экраном. Названия меню зависят от прошивки. Accessibility-действия требуют разблокированного экрана; API-запись не зависит от видимого экрана, но зависит от доступности сети/процесса. Не предполагается гарантированная бессрочная работа при OEM-убийстве процесса.

## Обязательная проверка на телефоне
- Установка, запуск и перезапуск на Realme / Android 11.
- Telegram: свой chat работает; чужой ID, группа, пересылка отвергаются; Stop прекращает polling.
- Работа при блокировке, потере/восстановлении сети и в режимах энергосбережения Realme.
- OAuth существующего аккаунта и совпадение уже существующих записей.
- Добавление одной небольшой тестовой записи с явным подтверждением, проверка количества в FatSecret; удаление тестовой записи вручную при необходимости.
- Два продукта, повторный `/confirm`, предупреждение о дубле, потеря связи после отправки записи и ручное разрешение блокировки без повторной записи.
- Фото/голос через выбранного провайдера; неполная порция требует уточнения.
- Keystore после перезапуска; отсутствие токенов в логах/backup; ограничение Accessibility по пакету и экрану блокировки.

Без этих проверок готовность MVP не подтверждена.
