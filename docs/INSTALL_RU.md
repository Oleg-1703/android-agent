# Установка на телефон

В 0.8.0 телефон получает Telegram, ПК разбирает сообщения через подписку Claude. Записывать можно прямо в FatSecret на этом телефоне или в эмуляторе ПК. Телефонный режим позволяет видеть запись на том же устройстве без ожидания синхронизации.

1. Установи выданный APK 0.9.3 поверх предыдущей локальной версии. Не удаляй старое приложение: так сохранятся токен, ID и настройки ПК. Test APK предназначен только для эмулятора, на телефон его не устанавливай.
2. На вкладке Telegram сохрани токен бота и свой числовой ID. Если они уже сохранены, нажми «Проверить соединение».
3. На вкладке ИИ включи «Записывать в FatSecret на этом телефоне». HTTPS-адрес, код и согласие на подписной ИИ сохраняются от предыдущей версии; заново их вводить не нужно. Нажми «Сохранить подключение ПК» **до перехода в системные настройки**.
4. Нажми «Открыть настройки управления телефоном» и один раз включи службу Android Agent. Это системный доступ Android для работы с FatSecret, а не подтверждение каждого приёма пищи. В самом FatSecret должен быть открыт нужный аккаунт.
5. Вернись, проверь связь с ПК, на главной нажми «Запустить». Во время распознавания экран можно выключить. Готовая еда дождётся разблокировки в очереди и запишется автоматически; во время ввода агент удержит экран сам, максимум две минуты. Команда `/today` открывает и читает FatSecret без записи новой еды и требует разблокировки в момент выполнения.
6. Отправь новый реальный приём пищи. Уже записанные приёмы для проверки не повторяй. [Примеры](ONE_MESSAGE_RU.md).

Для режима эмулятора выключи «Записывать в FatSecret на этом телефоне», сохрани и запусти агента. Тогда Accessibility на физическом телефоне не нужен, заполняется авторизованный эмулятор ПК. Автоматического переключения на эмулятор при ошибке телефонного режима нет. ПК и помощник работают в обоих случаях; API-ключи и подтверждение каждой цифры не требуются.

Telegram принимает только настроенный приватный чат с совпадающим отправителем. Второй приёмник того же бота запускать нельзя. Пересылки и группы отвергаются. После перезагрузки/принудительной остановки телефонный агент запускается пользователем заново. На Realme разреши фоновую работу Android Agent и отключи ограничение батареи.

Фото с подписью «Обед» считается готовым описанием и передаётся ИИ. Для длинного голосового комментария отправляй фото без подписи. Бот показывает этапы обработки; экран во время ожидания можно выключить. Если план уже готов, но телефон заблокирован, повторная отправка не нужна: очередь хранится зашифрованно и продолжится после разблокировки. `/status` только читает состояние, `/cancel` отменяет планы, которые ещё не начали ввод. При отсутствии данных штрихкода приходит отказ без записи, при оценке блюда - явная пометка оценки.

Код привязки сохраняется. После перезапуска временного HTTPS tunnel адрес может измениться; постоянный адрес ещё не настроен. Не публикуй код, токены и личные снимки. Диагностика приложения не содержит секретов. Физический Realme, реальный микрофон, сборка нескольких медиа и межустройственная синхронизация проверяются отдельно на телефоне.

Ранее реализованный экранный поиск и developer API относятся к отдельным режимам разработки и не нужны для описанной записи своей еды.

## Необязательно: служба специальных возможностей сама включается обратно

Android выключает службу специальных возможностей после обновления приложения, принудительной остановки и сбоя, иногда это делает и менеджер батареи производителя. Если служба выключена, бот один раз пишет в Telegram, как её включить (Настройки - Специальные возможности - Установленные службы - Android Agent). Сообщение приходит один раз за каждое отключение; распознанная еда ждёт в очереди.

Чтобы не включать вручную, один раз выдай приложению право WRITE_SECURE_SETTINGS. Подключи телефон по USB (включена отладка по USB) и выполни на ПК:

    adb shell pm grant com.oleg.androidagent android.permission.WRITE_SECURE_SETTINGS

После этого приложение само добавляет только свою службу в список включённых (другие службы не трогает) при открытии приложения, перед записью и при каждой проверке связи. Право выдаётся один раз и сохраняется при обновлениях (если приложение удалить и поставить заново, выдай снова). Без права ничего не ломается: работает ручное включение и сообщение в Telegram. Служба по-прежнему работает только с приложением FatSecret.

## Если запись не удалось сверить с дневником

Бот пишет «Возможно записано, проверь дневник FatSecret» и ничего не повторяет. Следующие запросы это не блокирует, ручное подтверждение «я проверил» не нужно; пометка в приложении необязательна и убирается сама при следующей записи.
