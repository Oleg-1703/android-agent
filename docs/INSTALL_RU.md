# Установка на Android 11+

Основной режим управляет установленным FatSecret через Accessibility. Developer-доступ и платный API не нужны. Для ИИ используется твоя подписка Claude Code на ПК; ПК и помощник должны быть включены. Команды `/meal` работают без ИИ и ПК. Состояние конкретной сборки и границы проверки - в [PROGRESS.md](PROGRESS.md).

## APK

Установи выданный локальный APK поверх предыдущей локальной сборки: постоянная debug-подпись этого ПК сохраняет настройки. Минимальный Android - 11. CI-артефакты подписываются временными ключами: они могут потребовать удаления старого приложения. Перед удалением проверь дневник и непроверенные операции; удаление очищает настройки и журнал. Проверка установки через Play Protect на Realme пока остаётся за пользователем.

Секреты хранятся через Android Keystore, backup отключён. Не отправляй токены, код сопряжения или пароль в Issues и чат. Для сообщения о проблеме есть «Диагностика для скриншота» без ID, еды и секретов.

## 1. Telegram

1. Открой вкладку Telegram, введи токен от BotFather и свой положительный личный ID. Сохрани, проверь соединение.
2. Открой бота и нажми «Начать». На главной Android Agent нажми «Запустить», дождись состояния «Работает». Отправь `/help`.
3. Этот же бот должен опрашиваться только на одном устройстве. При конфликте 409 останови второй приёмник. ПК-помощник Telegram не опрашивает, поэтому конфликт с ним не возникает.

Принимаются только настроенные private chat и sender ID; группы и пересылки отвергаются. Служба работает с постоянным уведомлением и явной остановкой. После перезагрузки или принудительной остановки запусти её снова в приложении. На Android 13+ разреши уведомления.

Помощь, статус, отмена и остановка не зависят от часов телефона. Свежесть действий проверяется по HTTPS-времени Telegram и монотонному таймеру Android. При неизвестном времени действия запрещаются. Offset сохраняется до исполнения: после сбоя запись не повторяется автоматически.

## 2. Обычный FatSecret

На вкладке FatSecret нажми «Открыть FatSecret» и войди в своё обычное приложение. Затем нажми «Включить специальные возможности» и включи службу Android Agent. Во время управления телефон должен быть разблокирован. Кнопка «Прочитать сводку дневника» проверяет доступ к экрану без изменения записей.

Браузерный OAuth-вход и developer-ключи не нужны. Старые формы скрыты под «Экспериментальный developer API» и не входят в основной сценарий. Ошибка 400 прежнего OAuth-входа не мешает управлению обычным приложением.

Accessibility ограничен пакетом FatSecret. UI-дерево не передаётся модели. Программа не обходит блокировку телефона, не меняет другие приложения и останавливается при неизвестных или неоднозначных элементах. Проверь, что не открыт чужой несохранённый продукт: агент сохраняет ручные черновики и не закрывает их ради нового запроса.

## 3. ИИ по подписке

Подготовь [помощник на ПК](PC_BRAIN_RU.md). На вкладке ИИ введи его HTTPS-адрес и код сопряжения с локальной страницы ПК. Это доступ к твоему помощнику, не ключ платного API. Включи согласие, сохрани и запусти агента снова.

Текст и выбранное фото отправляются в Claude через установленный CLI. Голос распознаётся локальной моделью на ПК, в Claude передаётся текст. Лимиты подписки сохраняются; при достижении лимита платный API не используется. Временный HTTPS tunnel меняет адрес после перезапуска; для постоянной установки нужен стабильный адрес.

## Добавление еды

Без ИИ, с сегодняшней датой:

```text
/meal обед банан=100
```

Приёмы пищи можно писать по-русски или как `breakfast`, `lunch`, `dinner`, `other`. Дата автоматически сегодняшняя; явный формат `/meal ГГГГ-ММ-ДД lunch banana=100` тоже принимается, но другая дата будет отклонена. Пока поддерживается один продукт за запрос. Поиск использует регион самого FatSecret, который может сам переводить подсказку; точный продукт всегда выбираешь ты.

1. Бот найдёт варианты. Проверь название, бренд, приготовление и описание порции. Выбери `/pick 1 НОМЕР`.
2. Бот поставит граммы и покажет предварительный просмотр. Проверь дату, приём пищи, продукт и вес.
3. `/confirm КОД` разрешает запись. Код действует 15 минут. `/cancel` отменяет черновик. Модель не может сама подтвердить запись.
4. FatSecret использует две стадии: SAVE на экране порции выбирает продукт, верхняя кнопка записывает выбранное в дневник. Исполнитель сверяет контекст, выбранное количество, имя и граммы перед верхней кнопкой.
5. После сохранения проверь дневник. До проверки действует блокировка новых записей. На главной Android Agent нажми «Я проверил дневник - снять блокировку» и пройди два подтверждения. Это только разрешает следующий запрос, ничего не удаляет и не повторяет.

С ИИ можно отправить «Сегодня на обед съел банан, 100 г», фото с подписью «Обед, 100 г» или голос до 120 секунд. Фото и голос ограничены 4 МБ. По фото вес не угадывается: при нехватке данных бот задаёт вопрос. Короткий ответ дополняет предыдущий запрос до 15 минут; после перезапуска ПК контекст теряется. `/cancel` сбрасывает текущий диалог.

Если ответ потерялся, проверь `/status` и дневник перед повторной отправкой. При неопределённом результате журнал сохраняется, автоматического повтора нет. Изменившийся экран или перезапуск службы делают старое подтверждение недействительным.

## Что проверить на Realme

Локальный Android 11 эмулятор проверяет основной runtime, но не особенности прошивки Realme. Проверь установку, включение Accessibility, чтение сводки, один собственный подтверждённый продукт, остановку, потерю сети и восстановление. Для стабильного polling при необходимости разреши фоновую работу и исключи Android Agent из энергосбережения. На заблокированном экране Telegram может отвечать, а действия FatSecret будут отклоняться.

Не снимай блокировку неопределённой записи до ручной проверки. Не запускай тестовый instrumentation APK на личном телефоне: он предназначен только для выделенных эмуляторов.
