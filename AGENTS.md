# Architecture

The 2026-11-17 screen UX correction requires accepting/parsing meals while the phone is asleep. Never call requireReady before PC inference. Captioned photos use the short batch window; only captionless photos retain the explicitly announced long voice window. Persist prepared plans encrypted and scoped to PC pairing plus Telegram bot/owner before execution.
